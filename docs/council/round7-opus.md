## #0012 · 1122 Ni! (Callbacks 9)

**The shrubbery status doesn't read cold** (GDD-12:89). “Hiring. Hide the Hendersons’ hedge.” fails for three reasons:
- “Hiring” has no subject. Next to a Bureau stamp it reads as the Bureau hiring, not the knights looking for a new shrubbery. That
  sense came from Sol’s full sentence and was lost in the shortening.
- It's an imperative. On the same card as the **Locked hint** row, “Hide the …” looks like a gameplay instruction.
- It's set in 1122. The knights can't be eyeing a present-day suburban hedge. Sol’s longer version had the same time slip.

The other Field Finds statuses are short Bureau stamps about the object (“Impounded · …”, “Under HR review”). Keep the Hendersons
callback, but set it in the present day, where the shrubbery now lives, and pick up the description’s “a nice one”:
- EN: “Repotted · Nicer than the Hendersons’ hedge. Don’t tell them.”
- FR: « Rempoté · Plus joli que la haie des Henderson. Ne leur dites rien. »

This also avoids any overlap with the repeat-pickup line, where the knights’ next demand is the herring.

The other 1122 changes work:
- **Coconut halves** (:96). “The swallow refuses to comment” is the film’s coconut-migration argument. The stuffed swallow sits on
  the same shelf, which makes it a joke between neighbouring items. It doesn't repeat that item's own African-or-European punchline.
  The launch line now has the horse joke to itself.
- **Shrubbery cover story** (:130). “Knights fall quiet at last. Neighbours suspect a shrubbery.” explains the Ni pill that stopped. It
  no longer clashes with the Accounting line.
